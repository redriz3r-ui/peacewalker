# Publication notes

PeaceWalker is being preserved as a public-source candidate.

Current scope: Swift walking app with HealthKit, location tracking, maps, sessions and progress views. About 2,000 lines across the main view and view-model files alone.

Preparation still required: Add README, screenshots, setup/permissions instructions and license. Exclude Xcode user state and personal walking/health data. Verify the app builds; existing test targets do not establish coverage or passing status.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
